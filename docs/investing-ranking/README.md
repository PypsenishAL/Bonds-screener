# Инвестиционный режим

Режим «Инвестирование» предназначен для сравнения условий покупки с удержанием до погашения. При переключении автоматически включаются инвестиционные колонки, сортировка по устойчивой премии и самостоятельный выбор категории AAA/AA/A/BBB/BB. По умолчанию показаны погашения через 1–7 лет; переключатель «Все сроки погашения» открывает длинные и короткие выпуски. YTM доступен как фильтр. Пользовательские фильтры не пересчитывают сохранённые баллы.

Расчёт: точная рейтинговая ступень, один выпуск каждого внешнего эмитента, два диапазона дюрации, медианный и взвешенный ориентиры и удаление представителей по одному. Ранжирование использует наименьшую сохранившуюся премию. Экстремальные значения отдельно проверяются до построения корзин. Неполная проверка не даёт основного балла.

Полное описание, параметры и ограничения: [уточнённая методика](refined_methodology.md). Балл — положение премии в категории, а не вероятность прибыли или надёжности. Отсутствие флага экстремальности не заменяет анализ кредитного риска.

Локальный пересчёт на существующих входах без сбора:

```powershell
python analyze_spreads.py
python -m streamlit run app.py
```

Для нового checkout необходимо предоставить локальные входы `data/daily_data/daily/bonds_daily.xlsx` и `data/history_data/bonds_history.csv`; полная история не публикуется. Публичное приложение читает проверяемый bundle `data/published` с `BONDS_DATA_MODE=published`. Новые поля хранятся в summary.csv с префиксом `investing__`, версией `conservative_exact_rating_v1` и конфигурацией в манифесте. Торговая схема3 сохраняется. Старые снимки открываются, но явно показывают отсутствие инвестиционного расчёта.

Проверки опубликованного набора кода:

```powershell
python -m unittest tests.test_spread_investing tests.test_investing_view tests.test_streamlit_app
```

Выбор бумаги открывает статус, причину ограничения, премию, место в категории и две сохранённые корзины с весами и ориентирами. В инвестиционном режиме торговая аномальность не подменяет новую оценку.
