# Реализация публикации GitHub

Реализованы `main.py --publish`, `--publish-retry`, подготовка и валидация
ограниченного комплекта, HTTPS-доставка с проверкой origin и всех push URL,
состояние повторной отправки и явный режим приложения `published`.

Проверено: 211 тестов, включая временные Git/bare remote; реальный сохранённый
комплект 44 468 196 байт / 12 файлов; Streamlit AppTest в опубликованном режиме
без exception/error; байты Git index совпадают с хешами комплекта.
Исходная история не публикуется. Реальный ежедневный сбор не запускался.

Независимое ревью выявило pushurl, повтор после staging и окно замены комплекта
до сохранения состояния. Исправлено: проверка push URL, принятие только своего
pending index/tree, durable installation intent и возобновление установки.
Дополнительно создан `.gitattributes`: `/data/published/** -text` необходим для
сохранения контрольных сумм на Windows/Linux. Это механическое дополнение к ТЗ.

Первый коммит отправлен в PypsenishAL/Bonds-screener, ветка main:
`a86425af1e20864edbd7ca8fc66100d58d3a9c00`. Удалённый SHA проверен.
LICENSE сохранён из существующего remote. Автор локальных коммитов настроен
как PypsenishAL / PypsenishAL@users.noreply.github.com. GCM настроен через браузер.

Облачная приёмка и измерение пика RAM на Linux ещё не выполнены. Для развёртывания
подключить GitHub repo, main, app.py в Streamlit Community Cloud и добавить secrets:

```toml
BONDS_DATA_MODE = "published"
```

До этой приёмки нельзя считать доказанной работу опубликованного приложения
или автоматического полного ежедневного цикла на живых источниках.
